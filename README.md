# 🧪 원소 실험실 시뮬레이터

118개 원소로 172가지 화학 반응을 발견하는 교육용 시뮬레이션 게임입니다.

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 배포 (Streamlit Community Cloud)
1. 이 저장소를 GitHub에 push
2. https://share.streamlit.io 에서 New app → 저장소 선택 → Main file: `app.py` → Deploy

> ※ 실제 반응을 단순화한 교육용 시뮬레이션입니다. 위험 반응은 절대 따라 하지 마세요.
